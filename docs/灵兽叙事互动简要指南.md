# 灵兽叙事互动简要指南

适用范围：供0.6.2正式包使用。稳定身份与叙事回访已在候选程序验收；正式0.6.2已安装，隔离启动主页和前端脚本检查通过。

## 如何开始

- 在主故事里遇见并了解生灵。遇见或起名字本身不代表已收服、听命或成为正式同伴。
- 继续互动时沿用同一只生灵的身份和经历；需要稳定回访时，在故事推进中明确表达希望记录为同一主体。正式人物记录承接身份与已发生的经历。
- 照料、熟悉、短哨等普通互动可以自然写进故事。请模型描述符合物种与已知经历的反应，不需要每日打卡，也不会因此自动获得数值提升。

## 保持故事连贯

- 通过明确的称呼、外观和共同经历指向已登记的同伴，避免把新遇见的同名生灵当成原来的伙伴。
- 告别或暂时分开不等于身份消失；之后回访时沿已有记录继续。
- 重要伤势、技能、资源消耗、移动与参战只有在现有规则和正式结算支持时才改变状态。

## 当前边界

- 物种适用的数值成长参数尚未确定，不能把主人修为、普通照料或短时训练换算成灵兽境界。
- 远程召回、瞬间移动、契约控制、灵兽专属战斗和受伤后恢复等能力，不因故事描述或玩家命令自动生效。
- 身份与共同经历的保存不代表完整御兽系统已经完成。未实际登记的事实不应当作已保存状态。
