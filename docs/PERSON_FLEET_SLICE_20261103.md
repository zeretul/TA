# 个人对舰与有限编队切片

## 原稿依据与范围

原稿《超神机械师同人世界稿》明确：A级旅者擅长空间遁逃（697–701行），A级破空之环能折断星舰（715–719行），超A级可以肉身硬撼歼星炮、一人成军湮灭舰队（17–24行）。因此不能把个人/舰船尺度当成绝对隔离墙，也不能反过来把“A级”变成任何舰队都必败的标签。低阶短暂真空闭气、名字叫“斩舰”的轻装甲刀术，不自动等于这些能力。

本次范围是玩家个人对登记单舰或有限聚合编队，保留既有舰对舰和个人交锋。不是完整舰队指挥：没有逐舰部件、轨道几何、增援、范围附带损害、敌方逐舰燃料/损管与分舰战利品。反向“玩家驾驶舰船迎战具名超能者”本次未接通。气力耗尽记录为失去作战能力的败退，并不证明已安全脱离；本次没有新增持续封锁、失压、营救或俘获状态，后续不得把这个结果擅写成安全回港。数值是明确可校验的游戏适配，不冒充原著物理常数。

## 正式结算

- `Battle.scale`继续表示敌方尺度。`player_scale`独立决定玩家装备、技能、血量和参战资产。旧活动战斗缺少新字段时仍按原同尺度规则读取。
- 个人对舰开战须显式提交`scale=person`和实际学会的`space_combat`技能ID；对手须有冻结的`ship_combat`画像。只达到A级/超A级，不构成资格与胜利。
- 选定能力按真实熟练度提供破舰力和防护，机动不靠等级自动膨胀。每轮实付维持气力；主动招式另付自身气力及耗材。合计不够时原子拒绝，不扣半笔费用。
- 舰壳门槛可让攻击完全不破防。个人手雷不继承破舰增益。毒、封穴、借力、软筋和近距离节点干扰不会变成整舰/整编队瘫痪。
- 舰队火控和个人机动决定暴露程度，随后结算实际护甲和持续防护。真正不破防时不再强制每轮扣1点血。
- 个人受炮火扣本人生命与伤势，不借用停泊舰船的武器、算力、护盾、燃料或血量，也不把个人败退写成停泊舰船受损。
- 胜利才发放已有登记奖励，每分支一次。维持气力耗尽是败退，不是免费脱离或获胜。每轮20秒、命令重试、分支与冷重开仍写入既有Story事实源。

## 新作者内容

- 三项能力：`xinghai-space-breach`天灾破舰力场、`xinghai-space-slip`折隙游走、`xinghai-space-dominion`超限星域战体。
- 使用已有A级/超A级进修札记及同阶基础作为学习来源，按玩家授权真实花费研习时间。旅者本人冻结技能表登记原稿明确的空间遁逃能力。既有s32/s34舰船操纵只增加有界机动值。
- 四个新遭遇：三舰轻掠夺编队、反超能重装拦截舰、五舰封锁猎杀队、24舰纵深封锁阵；原碎石带掠夺船补明确舰艇画像。不是自动升级刷怪，不增加重复奖励。
- 新局使用新版冻结目录；旧局不自动获得新技能或舰队画像，既有同尺度交战继续可读可执行。没有安装或迁移真实玩家存档。
