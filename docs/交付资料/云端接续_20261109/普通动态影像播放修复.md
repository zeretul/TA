# 凡人修仙普通动态影像播放修复

2026-11-09。开发版与正式版运行目录沿用了 2026-10-27 的媒体清单，2026-11-03 素材清单中已有的 17 段普通影像审核标记没有同步。2026-11-08 的运行备份已存在这一差异。两份清单的条目除这 17 个标记外一致，文件也逐件哈希一致。实际程序先按审核字段拒绝 HTTP 请求，播放器无法取得文件。

本轮只同步已审核的 17 段普通影像的媒体清单，更新开发和正式两个运行清单及校验文件。每套 124 个视频均核对原哈希，程序沿用当前构建。隔离实例复现 17 个 404 后，修复实例 17 段全部通过 HTTP 和 Chromium 播放。两个实际安装各检查全部 17 个 HTTP、Range 和抽播一段。107 段未审影像仍返回 404。试验使用独立数据。

完全退出后重新启动游戏。凡人修仙中，在已绑定影像的人物窗口点开画像。关掉「人物片段自动播放」时仍可手动点播放。以后安装更新应比对开发根目录 media/media.json 与两个运行目录的清单，避免只保留 MP4 文件而漏掉已确认的审核标记。详见[核验记录](普通动态影像同步核验.json)。
