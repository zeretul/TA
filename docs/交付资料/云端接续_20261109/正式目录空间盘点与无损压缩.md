# TA 0.7.0 正式目录空间盘点与无损压缩

2026-11-09。正式目录原来约 2.17 GiB，其中约 1,505 MiB 来自 .ta-game/release-backups 下两份 0.6.18 旧程序回滚副本。两份旧备份已按只保留最近两版的要求清理，21 份附带记录已独立归档并逐件校验。现用私人目录的文件合计 3.46 MiB，清理后复核了开发与正式两边 195 个现用私人文件，SHA-256 全部一致。

| 约 711 MiB 运行目录的原体积 | MiB |
| --- | ---: |
| TA.exe | 538.9 |
| 原有视频 | 88.4 |
| 运行肖像 | 33.1 |
| 外置网页、静态图和字体 | 36.5 |
| 更新器、搜索工具、媒体清单与其他 | 14.2 |

主程序含约 366 MiB 内嵌图鉴，余下是程序、内置世界规则及内嵌前端等。此次采用 NTFS LZX 透明压缩 32 个程序及文本文件。每套 918 个受管运行文件的 SHA-256 完全一致，占用空间各少约 126.1 MiB。正式目录现有文件逻辑大小约 714.6 MiB，按 Windows 文件压缩大小接口计算的占盘约 588.5 MiB。旧备份的删除另释放约 1505.1 MiB。

同一套 918 文件隔离对比前后，再用两个实际安装各核验 203 个网页文件、4 个旧图鉴地址与两份历史存档样本。旧存档样本从现用目录的历史备份复制到隔离数据目录，压缩前后快照哈希完全一致。测试未使用真实模型或改写现用数据。两套完整恢复点继续位于备份/恢复点。

适用范围为当前 NTFS 本机安装。选取受管清单中至少 64 KiB 的程序、JS、CSS、JSON 和 SVG，使用 Windows compact 的 LZX 模式。安装目录以外的打包大小与文件逻辑长度保持原值。复制到其他卷或替换程序文件后，文件可能恢复为普通存储。证据见[无损占盘核验](无损占盘压缩核验.json)与[旧程序备份清理](正式版旧程序备份清理核验.json)。
