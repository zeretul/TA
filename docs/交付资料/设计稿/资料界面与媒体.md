# 资料库、已知信息、界面、双语与媒体

适用版本：0.7.0；更新：2026-11-05。本稿依据当前实现、已确认决定与既有交付记录整理。

## 当前界面

一级菜单为游戏、资料库、世界包、游戏设置，底部为系统设置。游戏AI助手与方案预设归游戏设置。主故事以阅读和输入为中心，聊天、双修、战斗及必要信息窗口复用现有布局；查看资料不执行游戏行动。

## 资料与知情

- 原生资料、本局新建资料与游戏内已知信息分别表达作者来源和知情范围。作者目录的存在不代表玩家已掌握全部档案；秘密、传闻、已确认事实与历史消息不能混为一谈。
- 资料总览复用人物、物品、技能、地点、组织和事项等已有投影，按本局状态展示。相关跳转、搜索与收录不另外创造资源、权限或NPC。
- 人物详情、头像与已知资料保持同一身份；分类、标签和简介用于查阅，不创建另一份人物数据库。

## 图片与视频

图片可外置，稳定映射到人物、地点或定义，缺图仍可阅读和操作。动态媒体只在合适的交流或详情视图展示，避免主故事正文被头像与重复动画打断。图库原稿中的素材数量、尚缺名单和旧视频审阅记录是当时快照，不作为本版功能状态。

0.6.18交付时的17项缺图已经补齐并完成当批审计；这不表示任意后生成内容永远不缺图。新定义的可选配图沿现有去重路径，未配图像模型或生成失败时不阻断玩法、不反复自动扣费。视频人工审阅与玩法功能缺失分开记录。

## 语言与阅读

中英文使用独立资源并按当前语言显示；路线、内置事件、错误与空态都在此范围。普通行路与太岳灵潮英文遗漏已补齐。历史正文、玩家自定义文字和作者未提供译文的外部包保留原文，不承诺自动改译全部历史。

深浅主题、375与1440宽度的代表页面已有检查记录。浮窗、长文与草稿应可读可操作；这些是持续设计原则，不把每一种屏幕尺寸都列成缺失功能。
