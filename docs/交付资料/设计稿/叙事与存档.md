# 叙事、文风、存档与主故事衔接

适用版本：0.7.0；更新：2026-11-05。本稿依据当前实现、已确认决定与既有交付记录整理。

## 玩家体验

玩家通过选项或自由输入推进故事；聊天、战斗和资料窗口围绕同一局展开。顶部保留“新开一局、切换存档、删除存档”：新建故事保留原档，切换覆盖可用世界，删除前确认目标；分支是同一故事的不同历史，不等于另开一个人物。

## 当前规则

- AI负责场景、对白、动机和行动提案。数值、物品、时间、资格、奖励与终局以正式规则结果为准，正文不能另写一份相反结果。
- 玩家可以拒绝、暂缓、绕路或提出新办法。既有规则能表达的行动通过现有提交入口保存；不为普通生活逐项新增界面或固定任务。
- 私聊和群聊形成的商定行动暂存后，与玩家下一次主故事输入一起提交。讨论、承诺和已经执行必须区分；关闭窗口不会自动执行承诺。
- 六种推荐文风服务于主叙事、对白聊天、战斗等用途；切换影响后续生成，不重写已保存正文。旧“十二种推荐文风”不再是现行数量。
- 正式时间由实际行动推进；阅读、翻历史、切窗口、问价与查看资料不应自行消耗游戏时间。生成等待不等于游戏内等待。
- Story journal保存已提交事实；快照、索引与模型上下文不是另一套事实源。重试不得重复结算，分支不得读取未来事实；未完回合的动作草稿需要随恢复保留。

## 已有能力与设计边界

存档三入口、正式动作草稿恢复、常用自由输入与文风作用域已有实现。当前没有新增强制主线、每日签到或现实倒计时。任意模型、任意自由措辞都永不出错并不是已证明的产品承诺。

剧情助手可以分析已知选择、提出灵感与走向，不代替玩家执行，不凭分析泄露人物秘密或授予奖励。游戏不启用Goal，也不恢复写作、终端或自动化为游戏菜单。

## 后续维护

调整提示词时先检查是否已有规则与返回结果，优先纠正漏提交、人物串音、时间口径和正文冲突；只有实际结果或保存缺失时补代码。
