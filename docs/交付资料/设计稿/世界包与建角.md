# 世界包、创建人物、冻结版本与自创世界

适用版本：0.7.0；更新：2026-11-05。本稿依据当前实现、已确认决定与既有交付记录整理。

## 玩家流程

先了解世界，再加载世界包并创建人物。玩家可选现有出身、编辑或自定姓名、性别、身份与天赋；AI在该框架内补充来历、关系、地点和开场，不能用默认模板覆盖玩家选择。当前内置四世界共有16种出身，具体目录见[四世界内容与适配](四世界内容与适配.md)。

## 当前规则

- 世界包保存作者资料、规则、能力范围、角色模板与新局默认设置；每局绑定自己的版本和内容快照。更新文件不会使旧局自动获得新人物、新物品或新规则。
- 原生资料与本局新建资料分开。本局生成的人物、技能或物品先留在本局；明确收录时再沿既有编辑路径整理进世界包，处理来源、稳定ID和重复。
- 世界创建复用草稿、预览、修改、确认与保存流程。题材能力先确认，再绑定已有规则；自定义文字不自动创造一个可运行的战斗或经济系统。
- 侦探、悬疑等不必强制带等级成长。通用行动检定与题材数值规则各自表达真实支持的能力，不能把技能改名当成新题材适配。
- 同名人物不直接合并；世界、故事、分支、角色身份分别隔离。更换显示语言不改写作者事实、稳定ID或旧正文。
- 建角是准备本人的合法初态，不从旧私聊、失败项目或其他存档继承好感、资源与关系。

## 已替代的旧方案

三种固定开场、多处互相独立的预设管理、“本局补充”入口和只支持三世界的叙述已过时。凡人开局不默认全都属于黄枫谷或燕家；具体预设自身的门派身份仍保留。

## 内容接入边界

外部Markdown、世界书和人物卡是资料来源，不因写着“自动注入”就成为正式游戏内容。接入先核对来源与原著/同人/原创分类，再按现有作者结构和实际消费者合入；不迁入旧存档或私人聊天。

## 0.7.0 世界包显示词汇（2026-11-06）

共用前端与AI上下文读取本局冻结的gameplay.presentation，支持zh-CN和en-US；各语言可选combat、exploration、techniques、partner、energy五项短标签。中文每项最多40字符，英文80字符；使用单行纯文本。显示词汇不改变实际战斗规则、行动ID、资源或持久化字段。

例如作者可以为一个已有合法玩法规则的世界声明：
```json
"presentation": {
  "zh-CN": {"combat":"学院决斗","exploration":"魔法调查","techniques":"咒语","partner":"伴侣","energy":"魔力"},
  "en-US": {"combat":"School duels","exploration":"Magical investigation","techniques":"Spells","partner":"Partner","energy":"Magic"}
}
```

这是展示字段示例，不代表哈利波特或其他新世界的专有机制已经实现。缺省使用该题材的对应语言词汇，未知题材使用中性名称；不能按世界名字自动猜能力。旧档继续读自己的冻结资料，不用最新作者包回盖。通用世界包JSON/草稿保留此字段，目前未新增独立可视化词汇编辑表。

战斗面板按已声明且确有实际规则的能力选择；修仙与原生冒险接口拒绝混用。真实在场、无线电可接通、书信送达继续是不同条件，换名称不授予额外通信能力。

新增世界规划按用户决定：斗破、哈利波特、诡秘之主、低武紫川归冒险；三国、崇祯归经营。新包须分别核对成长、资源、战斗、制作、通信与风险机制，不以换词冒充规则适配。
