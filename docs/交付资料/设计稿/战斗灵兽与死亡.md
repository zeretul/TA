# 战斗、施展、灵兽、载具与死亡

适用版本：0.7.0；更新：2026-11-05。本稿依据当前实现、已确认决定与既有交付记录整理。

## 玩家体验

战斗使用已有独立窗口，显示己方真实状态、已知敌情、行动费用与不可用原因。玩家选择目标和手段，规则决定命中、消耗、伤势和胜负，AI表达过程。胜负、脱离和是否致命不能只由旁白宣布。

## 当前规则

- 已学资格、境界或等级、资源、装备、施展负担与目标条件参与行动校验。敌人沿其实际画像和合法动作选择，不凭模型临时创造技能或资源。
- 战斗结果回到同一Story、库存、时间和人物事实；同命令重试不重打、不重复发奖励。无实际开战的文字讨论不消耗战斗资源。
- 失能、败退和正式死亡区分。致命结果须来自正式规则及目标身份；死亡不能通过普通恢复抹去，保留历史及合法的分支选择。
- 灵兽先有持续身份、可知资料和成长记录，再就具体同行/战斗表达意愿并参与；不能当免费装备或一次性战斗数字。普通活着离场与真实死亡不同。
- 星海区分个人、机械和舰船尺度。资产的耐久、燃料、部署、维修与驾驶者生命分别处理；个人战败不自动扣停泊舰船状态。
- 个人对舰有独立资格、能力、持续消耗与对手画像。达到A级或超A级不自动破舰，个人控制不能随名称放大成整舰瘫痪。
- 碎冠已有防护、控制、精神伤害及高阶对手差异；不把同一攻击改名当不同流派。

## 首领与长线边界

世界BOSS使用现有遭遇、阶段、技能、奖励与回响。目录中有代表首领不等于所有设想首领、原著能力和长期战役均已制作。新增首领应使准备、打法和战后选择有差别，避免只堆血量；更多首领属于内容扩展，不自动变成当前缺项。

## 沿用与检查

保留真实消耗、合法候选、胜败结果、脱离、冷恢复和分支的一致性。天然模型战斗、规则夹具与高阶批量成长是不同证据；旧设计里的“尚未开发战斗弹窗”不再适用。
