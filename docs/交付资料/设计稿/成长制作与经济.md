# 成长、学习、制作续作、装备与经济

适用版本：0.7.0；更新：2026-11-05。本稿依据当前实现、已确认决定与既有交付记录整理。

## 共通玩法

获得可信学习来源，投入本题材的时间与资源，学会后实际使用；通过劳动、交易、探索与制作取得有去向的资源。成长应开放新的做法，而不只是改一个境界名称。修仙、武侠、星海与西幻使用各自规则和货币，不套一份改名后的数值表。

## 现行设计

- 凡人修炼、突破、恢复和寿元沿修仙规则；武侠、星海和碎冠沿原生题材成长、学习、训练、工作与休息规则。规则上限和前置条件以本局冻结版本为准。
- 功法、技能、装备、丹药、阵法与符箓的效果必须有实际消费者。品色和名称不能代替效果预算、门槛、代价或持续时间。
- AI可基于已支持的模板提议新技能、功法、装备与制作方法，由现有规则检查并登记到本局；登记定义不等于学会、制成或取得物品。
- 购买、出售、转交、使用与装备都改变真实库存或钱袋；同名异品质、数量和物品实例不能混并。问价不扣钱，失败不能扣半笔费用。
- 炼丹、炼器、制符、阵法已有制作路径；“只有三艺，制符未实装”的旧状态失效。当前不要求把所有创意技艺补成独立小游戏。
- 个人制作已支持分段投入与继续原批次：开工投入材料，未完工保存工时，完成后才发成品；续作不重复扣材料，重放不增加工时或再次发货。已有失败结果不能靠重试重抽。
- 需要真实工具、地点、工作设备、专业或燃料的配方仍须满足条件。制作暂停不凭空报废，也不自动变成次日开工；叙事采用本题材正确时间单位。

## 已接通的代表链

凡人护身符可以分两次各1小时完成；星海外骨骼可以分两次各6小时装配。武侠、星海、碎冠复用各自配方与规则支持续作。两条真实模型代表链与三题材规则回归的覆盖不同，详见交付记录，不混成所有配方均自然试玩过。

## 保留的取舍

不恢复已撤回的额外craft_context/story_world_context叙事限制和A16图纸改写；不增加现实生产倒计时、无风险造卖套利或组织自动工厂。具体公式与价格查当前规则和作者JSON，旧数值附件仅供追溯，避免设计稿再维护一份会漂移的公式副本。
