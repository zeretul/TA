# 事件任务、行路探索、公共事件与长期后果

适用版本：0.7.0；更新：2026-11-05。本稿依据当前实现、已确认决定与既有交付记录整理。

## 核心循环

观察和交流获得线索，自由决定投入与风险，行动形成真实结果，再通过人物回访、路线和机会变化看到后果。玩家可以同时挂着多件事，自主排序；没有每天必须清空的任务列表。

## 当前规则

- 区分叙事素材、已登记任务和已经发生的事件。素材卡帮助AI发挥，不必每张都做成固定任务；只有已登记或正式提交的结果才能结算奖励、库存、资格与时间。
- 行路有真实起终点、路线和耗时。探索允许调查、准备、深入、取少量资源、保全、拆取、离开和回访；失败改变已有现场，不能靠重开刷新完整奖励。
- 秘境使用主故事推进与信息面板，复用已有探索规则，不恢复早期方案中的独立经营操作台或强制走格子流程。
- 回响需要实际条件、经过正式游戏时间以及本人接触或可知途径；到时间不等于全世界自动知道，离场不抹去已经形成的后果。
- 开放事项、承诺和截止时间沿Story保存。真正到期、资源不足或关键分歧才按规则打断长行动，不为制造刺激每轮强加代价。
- 世界时间、年龄、寿元、NPC成长与事件使用同一正式时钟。关游戏后的现实等待不推进世界，不建立全图离线模拟。

## 潮信渡的当前代表设计

到开局正式游戏时间36小时之前，可在渡头了解并完成潮尺校准，开放10小时短渡；截止针对校准，不是要求所有航行在截止前结束。错过后可复核外汊，开放11小时水路；原12小时旱路仍可走。未亲自参与的人不能凭空知道隐情。

早到、晚到和不同处置保留各自路线、记录与实际耗时；晚到并非删档失败，也不自动补发早到资格。晚到真实模型航行、到达与重开已有记录。

## 内容边界

三题材探索场地、合作切片、碎冠古灯塔与既有回响已接通，但有限内容不等于无限可变关卡或系统级全世界沙盘。早期长期目标讨论中的每件终极装备、每条个人任务与未来大势力战争并非已经制作。
