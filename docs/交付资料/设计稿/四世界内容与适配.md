## 各自的玩法

- **凡人**：修仙成长、突破、功法、四艺、灵兽、宗门和灵石经济；原著人物、同人改写和原创人物须区分来源。关系、时间、知情与资源仍按统一事实规则。
- **武侠**：本题材内力、武学火候、铜钱与江湖生活；当前自制成长支持1–40级八阶段，有学习、训练、装备、制作、演武、行路与回响。不能把凡人修为换名就称适配。
- **星海**：本题材气力、伊纳、机械材料、设备、无线电及个人/机械/舰船尺度；当前自制成长支持1–60级八阶段。机械战损、维修和受限个人对舰已有消费者，不等于原作无限军团或完整宇宙战争。
- **碎冠**：原创西幻生活出身、学习制作、组织事务、调查、古灯塔探索、高阶协商与战术对抗，沿自己的作者内容和题材规则。

## 对标方法

武侠和星海按凡人的六类体验核对：生计资源、成长学习、行路、制作与战斗、失败与重试、回响与分支保存。对标是每类存在有意义的真实结果，不是强迫题材使用相同货币、物品名称、技能数量或境界公式。

四世界16个出身已有本机模型开局与等待记录；武侠/星海成长至上限和部分高阶对比使用规则路径，不称全部由模型自然玩到。自然玩法、规则测试、内容数量分别记录。

## 0.7.0 世界包显示词汇（2026-11-06）

共用前端与AI上下文读取本局冻结的gameplay.presentation，支持zh-CN和en-US；各语言可选combat、exploration、techniques、partner、energy五项短标签。中文每项最多40字符，英文80字符；使用单行纯文本。显示词汇不改变实际战斗规则、行动ID、资源或持久化字段。

例如作者可以为一个已有合法玩法规则的世界声明：
```json
"presentation": {
  "zh-CN": {"combat":"学院决斗","exploration":"魔法调查","techniques":"咒语","partner":"伴侣","energy":"魔力"},
  "en-US": {"combat":"School duels","exploration":"Magical investigation","techniques":"Spells","partner":"Partner","energy":"Magic"}
}
```

这是展示字段示例，不代表哈利波特或其他新世界的专有机制已经实现。缺省使用该题材的对应语言词汇，未知题材使用中性名称；不能按世界名字自动猜能力。旧档继续读自己的冻结资料，不用最新作者包回盖。通用世界包JSON/草稿保留此字段，目前未新增独立可视化词汇编辑表。

战斗面板按已声明且确有实际规则的能力选择；修仙与原生冒险接口拒绝混用。真实在场、无线电可接通、书信送达继续是不同条件，换名称不授予额外通信能力。

新增世界规划按用户决定：斗破、哈利波特、诡秘之主、低武紫川归冒险；三国、崇祯归经营。新包须分别核对成长、资源、战斗、制作、通信与风险机制，不以换词冒充规则适配。
