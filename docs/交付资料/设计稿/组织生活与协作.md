# 身份日常、家族宗门、组织协作与势力变化

适用版本：0.7.0；更新：2026-11-05。本稿依据当前实现、已确认决定与既有交付记录整理。

## 设计目标

让身份和人情在生活中产生实际作用：能接触谁、可以借用什么、承担什么义务、怎样共同解决一件事。玩家既可以劳动、学习、经营关系，也可以加入组织、参与事务或拒绝请求；不把文字冒险改成财政审批平台。

## 当前行为

- 身份、组织成员关系、负责人和权限来自本局事实；群主身份、口头称呼、背景介绍或高好感不自动授予组织资产处置权。
- 已有组织事务与有限NPC协作可记录真正参与者、意愿、投入、时间和结果。不能把“对方答应”立即写成“工作已完成”，也不能由玩家一句话花掉全组织资产。
- 人物可在玩家离场期间按已成立的安排办事；回访由当事人结合原承诺说明结果，保存新事实并影响下一步。普通定性事务优先用AI规则与已有承诺机制，不加一套后台生产引擎。
- 钱财、物品、作业进度和奖励确实变化时仍经过现有规则；没有投入、资格或结果消费者，正文不得自行补发。
- 长期势力变化以与玩家相关的事件阶段、来源明确的消息和可参与后果表达；远方未知保持未知，不每轮全组织自主演算。

## 已有代表结果

碎冠冷锤工坊的负责人承诺、玩家离场7小时、回访确认及工具借用安排已有真实模型与冷读记录。此链证明非数值组织事务能够留下后果，不代表所有组织已经具备无人值守生产。

## 不自动扩张的部分

完整宗门财政、人员排班、多NPC贡献统计、永久队伍忠诚或饥饿、全球战争沙盘和无限自动生产属于扩展设想。当前旧稿中的经营名称应理解为具体可参与事务，不能据此自动开设整套经营系统。
