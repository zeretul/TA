# 模型作用域、程序目录、更新与交付

适用版本：0.7.0；更新：2026-11-05。本稿依据当前实现、已确认决定与既有交付记录整理。

## 模型与提示词

游戏复用已有Endpoint/ModelProfile配置。主故事、聊天、双修及图像用途遵循各自已有绑定，界面应说明实际使用对象；双修须独立选择ProfileID，未配不能暗中借用主故事模型。修改一个被多处引用的底层档案可能影响多用途，切换单个用途的绑定则只影响该用途。

内置模型说明新增或职责内修改时优先中文，不重复注入中英文；JSON字段、枚举、ID和协议名保持原样。模型按游戏语言输出。旧提示词中仍存在英文说明，不能把“统一中文”的维护方向写成已经全仓转换完毕。

真实调用使用所选档案的上下文与输出预算。连接失败、模型不存在、格式错误和人物拒绝分别说明，不能将技术错误伪装成NPC态度，也不擅自切换服务。凭证留在本机配置，不进入设计稿、世界包、导出材料或验收日志。

## 本机目录

- 开发源码：TA-开发版根目录；开发运行文件在game，私人配置与数据在dev-data。
- 正式运行：同级Text Adventure，沿原启动.bat；正式目录只放游戏运行需要的程序、资源和说明。
- 下载原件与恢复产物：云端交付；设计：docs/交付资料/设计稿；历史资料：资料归档；回滚：备份。
- 本机临时验证放.ta-dev对应批次，结束后清理自身缓存、程序副本和隔离数据；不能再次向旧DENOVA目录或E盘根散落文件。

## 版本与交付

当前应用版本0.7.0，版本号只用数字。开发版和正式版采用保留本地定制的local程序，TA-github采用share程序；通用功能同步，分享不带本地专用提示词、续写控制或私人配置。维护详见[三版本约定](../../三版本维护.md)。本轮未改原存档、模型选择或账户设置。

后续程序同步要让前后端与资源保持一致，核对清单及受保护数据；实际安装和公开发布遵守当批授权。现有旧Git HEAD不是最新源码备份，不可用旧提交覆盖当前开发树。

## 更新范围

本地更新、忙时拒绝、回滚和既有迁移路径与在线发布源是不同事项。TA自己的公开仓库、发布方式与可用线上源属于外部发布配置；不能回退使用原DENOVA更新源，不列成当前玩法缺失。
