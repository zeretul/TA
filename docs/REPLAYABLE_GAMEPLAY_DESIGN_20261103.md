# 可反复决策的探索：本轮新增玩法设计

日期：2026-11-03。状态：**设计与源码核对，不是已实现/自然 AI 验收声明**。实施结果由本轮验证报告补充。

## 结论：做两条互相支持的循环，不再堆一个管理平台

1. **探路与取舍**：先看迹象，也可以不调查就直接行动；根据自己真正持有的工具、技能与消耗品，选择慢行、专长或冒险的方法；拿一部分就走，或为核心发现承担更高风险。
2. **保全还是取用，及有变化的回访**：现场结构不是只等玩家领取的宝箱。拆取能立刻获得制作材料，保全会放弃这笔即时收益，但在正式世界时间推进后，打开不同的局部通路与一次性发现。退出、受挫、重来均留下痕迹，不重置成可刷副本。

两条循环共用现有 Realm，不造势力经营页、每日任务、全局倒计时或第二套任务/存储。首版三世界各一处完整小场地，**不宣称三个小场地已经提供无限内容**；先交付可验证的选择质量，而不是用随机换名冒充耐玩。

## 1. 已有能力与真正薄弱处

源码已查：`internal/interactive/story_quest_choices.go` 有选择结果、真实耗时、失败后的准备条件、延迟回响；`adventure_routes.go` 已有 A06 选择开启水路的消费者。`internal/character/memory.go` 已区分亲历/转述/传闻/推测/秘密及知情者。它们不是本轮新增玩法，不能重新命名后计功。

本轮修改前，`internal/exploration/realm_definitions.go` 只注册古修洞府：五区域、两件物品、所有连接公开、`Challenges` 为空；注释明确说没有可裁决挑战。`story_realm.go` 接了 enter/move/reward/exit/reenter，奖励写入偏凡人行囊，没有三题材的勘察/方法成本/局部风险/处置后回访循环。因此原探索容易成为走格子取物，而不是做决定。

现有探索层已有 `Discoveries`、`ResolvedChallenges`、`GrantedRewards`、定义哈希、分支绑定、已知视图、一次性奖励与重入保留。**继续用这些，不重造探索引擎**。任务的 `planQuestChoice` 当前依赖 AdventureRules；不能为了复用 echo 让凡人冒充武侠/星海。回访采用同一个 StoryClock 和 Realm 实例历史即可。

## 2. 五个候选与取舍

|候选|玩家新行为与结果|决定|
|---|---|---|
|有调查、方法和撤退的险地探索|判断已知风险；带绳、制符、学会抢修后改变走法；留下部分所得离开|**实施**。已有 Realm 消费者可靠，新增决策而非增加目录数量|
|发现的取用/保全与回访|眼前材料与后续通路二选一；回到旧地点看到不同入口和耗尽痕迹|**实施**，并入同一模块，不另建资源经营平台|
|全局自主势力沙盘|多方竞逐、站队、调停、世界自行演化|本轮不做。已有任务回响能解决部分需要；全局模拟会扩大到大量不可验证的远处事件与管理噪音|
|同行者合作与分歧|邀请真实认识的人同行，按动机选择参与/拒绝，分担方法|保留下一优先级。须先厘清在场、出行与协作收益的消费者，不能只加好感条或虚构全组织效忠|
|战斗流派/装备组合与敌人适应|改变配装与出手顺序，针对敌人准备|本轮不另起系统。已有大量原生战斗规则；先让工具和制作产物在探索产生新用途，比再叠数值层更直接|

## 3. 首版共同机制：有限风险，不强制固定流程

### 3.1 行动与风险预算

每个场地约 3–5 个区域；首版把外缘可取处与障碍并入入口，保留入口/核心/回访侧区三个真实区域，减少无意义的走格子。入口本身可退出；所有深入区域都保留一条已知退路，受挫不删退路。普通移动可有很短的正式耗时，但**安全退行不增加风险**。不用现实时间推进，不因关游戏而失败。

建议初始局部风险 0、警戒线 4；UI 不必突出裸数字，可用 4 格及题材名称。它表达现场余地，不是角色等级，也不是六色品级。下表是可检验的首版预算，实施可在保持路径差异的前提下微调。

|行动|时间/风险|实质效果|
|调查当前障碍|10 分钟，风险 +1，仅一次|得到有来源的线索，开放慢行方法；不泄露内室全部内容|
|循线慢行|20 分钟，风险 +1|不要求专门技能，打开核心通路；必须真的已调查|
|凭专长或准备的方法|约 10 分钟，风险 +0|不同世界检查不同真实资格并扣真实成本，跳过调查也可行|
|强行开路|5 分钟，风险 +2|无须先调查；公开提示会破坏完整性，使后续保全选项不同或不可用|
|取外缘少量材料|5 分钟，风险 +1|立即自动入真实库存，仅一次；拿了可以直接退走|
|保全核心|20 分钟，风险 +1|没有同份即时拆取材料；保存处置，记录回访条件和正式时刻|
|拆取核心|5 分钟，风险 +1|即时获得少量真实材料，核心不可再保全；留下拆取痕迹|

**预算例子**：调查 1 → 慢行 2 → 保全 3 可成功；若先多拿外缘，随后保全会触及 4，必须明确提示。专长方法 0 → 外缘 1 → 保全 2 可多带东西，但前提是此前正常取得工具/技能/材料。强行 2 → 拆取 3 更快、无需等待，但失去完整结构的后续用途。不能靠反复调查/离开重进重置风险。

准备不是强制新增一个“准备按钮”。去市场买绳、自己制符、正常学习抢修、休整恢复，就是准备。可以少量提供一次性稳定现场的方式，但必须有真实代价，不能无限刷减压。

### 3.2 受挫是另一条路线

会触及风险线的行动在提交前明确显示“此举将使核心关闭/只能回收残余”；首版使用确定性代价，不伪造随机胜率。行动仍花其明确成本，但不同时给完整成功奖励。记录 setback，核心完整通路关闭，开放一次性残余线索/少量材料及退路；已到手外缘材料保留。

受挫后可离开，正常休整、制作、交易或去别处。回访仍是同一实例：看见损坏与残余入口，不把完整核心刷新出来。不是无尽失败惩罚，也不增加凭空死亡、强制战斗或剧情结局。

### 3.3 不把玩家锁在菜单里

主故事自然输入仍是正式入口。玩家可用自己的描述表达方法，AI 对应到当前实际存在的方法 ID；原有自由交流、拒绝、暂缓、离开照常。未建模的创意可以自然演绎，但不得凭一句话虚授材料/资格/成功。选项是可做之事的说明，不是必须依次执行的步骤，也不是世界全部可能性。

## 4. 三题材不是换词：入口、准备、手段、后果

以下名称是本轮新增的小型场地，不改冻结作者世界包、不覆盖 A16，也不冒充既有重要人物旧案的官方结局。

### 凡人：山溪旧药窟

- 入口：`yue.market.outskirts`。现有 `route_036:forward/reverse` 能从公共坊市往返，不能用测试直接置地点替代可达性。
- 核心选择：保留封住渗流的旧阵源，或拆取阵材。外缘有少量 `material.herb.green_vine`；拆取给 `material.stone.ward`，用途分别接现有炼丹和阵材制作。
- 普通法：调查水迹后沿旧槽慢行；没有对应法门也能取得部分发现。
- 准备法：真实持有并消耗 `talisman.ward.lower` 一张，经适用境界校验后护住通过；符不是万能解谜钥匙，不赠新法术。也可采用服务能验证的已学术法，但不得把“会修仙”推成会所有法术。
- 保全回访：正式时间推进至少一小时后，渗流退去，侧面旧储物位可达；里面只放一次性已登记材料/有来源的观察记录，不是药草一小时无限长回。
- 拆取/受挫回访：侧位不恢复，只留破损通路和残余线索；已取阵石不再刷新。

### 武侠：潮信渡搁浅旧舟

- 入口：`lanchuan-l02`，现有道路连接澜口城、白鹭渔村；不是凭空出海副本。
- 准备法之一：在澜口城用真实铜钱购买 `lanchuan-i28` 三爪带钩生麻绳（当前目录价格 30）。持有绳才可固定穿行；普通系绳不应凭空扣内力，也不把绳消耗掉。
- 专长法：已学 `lanchuan-s34` 舟楫水战，按冻结技能的 `Cost=6` 扣实际内力，利用水势通过；不能仅凭主角文字自称船工。
- 普通法：观察吃水和受力后绕外舷慢行；强拆可快些取铁件，但会破坏船体支撑。
- 核心选择：保全绳路与船体支撑，或拆取铁件（`lanchuan-steel`）；外缘可获得少量 `lanchuan-herbs`。保全让正式六小时后的落潮侧路可达；拆取留下别的残余/公开痕迹，不返回原样。
- 与凡人区别：工具是**持有资格而非耗材**，船工专长消耗原生内力；风险是水势与船体余地，不是阵法反噬。相关见闻可以讲给真正接触过的人，但不自动给予整个船帮好感或通行权。

### 星海：47 号井旁检修舱

- 入口：`xinghai-l05`，`xinghai-route-l01-l05` 从 47 号减压长廊正式行路 15 分钟可达。
- 普通法：观察隔离标识后逐段断电、从维护通道慢行；持有 `xinghai-prybar` 合金撬棒可选择物理拆开，不将无线电当万能扫描/骇入器。
- 专长法：已学 `xinghai-s02` 电路短接与飞线抢修，按冻结 `Cost=6` 扣气力，消耗 `xinghai-i34` 合金丝一份，保住辅助供电并通过。设备尺度/真实库存不能跳过。
- 核心选择：保留供电完成离线诊断，或立即拆取导线。前者在正式一小时后使检修侧柜可打开，后者即得材料但关闭供电侧路。所得为 `xinghai-i34`/`xinghai-i37` 等真实机械材料，不是凭空战舰、神秘权限或私人频道。
- 与另两题材区别：技能与**实际消耗材料**一起构成方法；供电结构被拆后不能再许诺在线诊断。若首版加入部署资产方法，必须通过原资产健康/燃料/禁用时刻与尺度消费者，否则不展示这条方法。

各场地核心材料建议仅 1–2 份、外缘 1 份，低于一套完整高阶装备。探索替代一部分买料，不把所有制作变成保证套利；不同配方原本的经济不均衡需另行审视，不在本轮偷偷改作者报价。

## 5. 第 1、3、10 轮究竟变了什么

这些是可自由打断的代表路径，不是固定脚本或强制十轮时长。

|阶段|没有专门准备的玩家|已有相应准备的玩家|
|第 1 轮|看见当前迹象、剩余余地、外缘与障碍两方向；可取少量就走或先调查|看见真实工具/技能开放的第三种方法，能决定是否花符/内力/材料|
|约第 3 轮|已拿外缘者风险更高，可能放弃核心；调查慢行者可保全，但无法无成本全拿|投入准备换来较低风险，可兼顾外缘与完整核心；准备确实改变路径而非加一个文案标签|
|约第 10 轮|曾强拆/受挫者回访看到残余路径，不再能拿完整核心；可用先前材料制作或交易|曾保全者在实际训练/劳作/旅行/休整推进时间后回来，侧路现在真的可走；可取一次新发现，再把它用于现有制作/自然交往|

不同分支选不同处理方式后，其通路、材料、风险与回访事实必须不同。差异要能从正式投影读出，不能只写一段“他记住了你”。

### 5.1 保全的长期消费者：已勘明的小捷径

设计复核发现：若护符价值 12，而消耗它只为额外一份价值 2 的药草，准备收益过弱；若保全只是晚些拿两份药草，也不足以与眼前阵材形成有意义取舍。因此本轮采纳**真正走通回访侧区后开放一条可重复使用的小捷径**，而非增第四个副本或膨胀奖励。

|新增双向 ID|已有正式端点|原路/新路分钟|新增地形依据|
|---|---|---|---|
|`realm-shortcut-herbcave:forward/reverse`|`yue.market` ↔ `yue.market.outskirts`|30 / 15|从药窟侧区验明高于渗流的旧背路，避开集镇外的一段绕行|
|`realm-shortcut-tideboat:forward/reverse`|`lanchuan-l02` ↔ `lanchuan-l03`|720 / 660|首次落潮到侧舱后找到高岸纤道，只省局部泥滩绕行，不把半日路变瞬移；之后不依赖永远低潮|
|`realm-shortcut-servicebay:forward/reverse`|`xinghai-l01` ↔ `xinghai-l05`|15 / 5|检修侧区打开可手动通过的维护通道，不等于通讯权限或驾驶资格|

原路分钟来自现 `journey_routes.go` 与 `assets/adventure-routes.json`；新增分钟是本轮新路径的设计值，**没有原作者米数或实测距离作计算依据**，不伪称原稿数值。它是不同路径缩短局部绕行，不是给同一路程全局加速。旧路仍保留。

实现建议独立 `internal/interactive/realm_shortcuts.go` 注册六条路径。`journeyOptionsFrom` 与 `planJourneyStretch` 必须共享同一资格谓词。资格是**当前分支**实例已有成功 `.return` 方法，且真正 `move` 到 `.side`；因此 `.return` 只打开连接，不提前授予侧区 Area 发现，实际移动才登记。不能要求先拿侧区材料才给捷径，也不能仅等到时刻就自动开放。

地理知识一旦真实获得可以保留，不因后来多拿外缘而受挫就抹掉记忆。角色仍要先从 Realm 合法退出、站在对应外部端点，才能走这条路；不是从深处瞬移到市场。新路有独立名称/本地化 key，使同端点的旧路与捷径在现行路面板和 World Actions 中可辨。

另一个已确认反例：拆取成功后故意调查触线，不能再领一份残余而使失败增利。`strip` 与 `cache` 成功记录同一 `core_taken` 事实，`residue` 排除此事实。尚未拿完整回访所得就受挫，可以走残余补救；完整所得和残余不双拿。

## 6. 最小数据与接口契约

不要照抄成万能 DSL；这是最多三种场地的小型冻结定义。实现者可删去没有实际消费者的可选字段。

```text
DungeonDefinition.ExploreRules? = {
  pressure_label, pressure_limit,
  approaches[]: {
    id, area_id, kind, group_id?, title, description,
    required_discovery_ids[], excluded_decision_ids[],
    duration_seconds, pressure_delta,
    eligibility/cost (固定类型：真实技能、物品持有、耗材、原生能量),
    discoveries[], resolved_challenge_ids[], reward_ref_ids[],
    return_delay_seconds?, return_effect_id?
  }
}
DungeonInstanceSnapshot.ExploreState? = {
  pressure, used_approach_ids[], decisions[group_id] = approach_id,
  setback, return_due_seconds
}
```

- 发现/回访痕迹继续使用既有 `Discoveries`，一次性所得继续使用 `GrantedRewards`；不要再建资源清单。数值风险与互斥处理有明确类型，别从中文事实字符串反解析。
- 新世界行动仍是 `world.action=realm`；最少加 `realm_action=survey/approach/resolve`、`approach_id`（若统一成一个 approach 动作更简单也可）。不加第二个可写主入口。名称明确的拆取/取用可在同一事务自动给其所得，不增加“完成后领奖”。
- 成本/资格由 Story 层根据冻结原生规则与正式 actor 核验，纯探索层只决定实例转换；不能接收模型传入成功、奖励数量或压力值。
- `RealmRecordEvent` 携正式 `clock_before/after`，所有时间经 `storyIntervalEvents`；不混同真实墙钟。回访可达条件由记录时刻 + 当前 StoryClock 派生，读页面不写状态或发奖励。
- 方法可见视图返回：方法 ID、自然语言效果、真实成本、阻碍原因、是否导致受挫。只投影当前位置和已知条件；不要发完整隐藏奖励表或未认识 NPC 秘密给模型/玩家。
- 同一方法重试返回原结果，不重复扣费；与别的命令复用 ID 则拒绝。重生/分支/冷重开继承同一已有 journal 机制。

|`internal/app/realm_app_service.go`、现有 API 类型|透传同一已知视图，无新资料库/账户/Store|
|`web/src/features/interactive/components/realm-window` 与 `realm-types.ts`|在原探索面板显示当前风险、2–3种方法、成本、已做选择和回访线索；双语、无新一级菜单|

`story_realm.go` 已长，新增独立职责应放邻近文件，不继续把所有逻辑挤入该文件。作者 JSON 三包不动，不改六色品级、成长尺度或高阶内容。

## 7. UI：帮玩家做选择，不强迫开工作台

原 Realm 面板是只读事实入口，继续保持。以“所在/局面”“可以尝试”“已发生/回来会有什么变化”三层展示；外缘所得已入背包要明确说已取得，不出现领取红点。方法展示时间、实际耗材或持有要求，缺条件可看原因；不能仅给漂亮动作名。

允许加入“放入行动草稿”帮助发现操作，但它不提交、不改状态，不覆盖非空草稿，不串 story/branch，用户仍可自由编辑/不发出。若这会扩大现有草稿风险，首版仅呈现可读方法，主输入自然写出即可。

界面中不露内部 command hash、Gate、receipt、verification 等工程语言。隐藏内容只给可理解的迹象；失败提示仍给退路/另法，而非一个空错误。375px、深浅、中英、长名字、载入/失败重试、关闭、分支切换须实际查看。

## 8. 代表验收：不要用测试存在代替玩通

1. **可达与起步**：各世界从正式建角/既有路径走到入口；普通玩家未持专门工具也能外缘取物/离开。测试直接置初态只能标规则夹具，不能冒充自然取得链。
2. **路径分化**：同一实例初态分别走慢行、强行、专长；时间、成本、核心完整性、可见方法至少一项实质不同；不同题材分别核符消耗/绳持有与内力/机械技能与合金丝。
3. **三段预算**：调查→慢行→保全可完成；多取外缘导致风险线时先提示，提交后真实受挫且不拿核心成功奖励；旧所得仍在。
4. **退出继续**：在外缘拿一份后离开，正常交易/制作/训练仍可进行；未接受任何任务也可探索；拒绝/无行动不产生压力。
5. **互斥与回访**：拆取不能再保全；保全到时前侧路不可用，到时后通过真实行动可走；拆取/受挫分支回访路径不同。浏览或休眠不会替玩家结算时间/奖励。
6. **新用途**：凡人探索材料进入原炼丹/阵材消费者；武侠真绳或舟楫技能改变方法；星海真抢修与材料进入成本，探索机械材料能被原制作消费。至少每题材一条非只看描述的消费者断言。
7. **无刷取**：重复请求、重进、再调查、反复看面板不增加库存/降低风险；已领取物品冷重开仍已领。
8. **持久化**：关键分歧前分支，两个分支得到不同处置且互不泄漏；冷重开与重试完整一致；改用别世界的 ID 拒绝无扣费。
9. **边界**：缺材料/技能/能量、已装备物不能误当散料、战斗中移动、陈旧 head、混合另一个耗时行动，都不发生部分扣费。
10. **AI 边界**：规则/合成 UI 测试可实际驱动上述流程；没有授权模型 API，就明确自然输入到模型选动作/长篇一致性仍未验，不写“AI已通”。

## 9. 对 DOT_TASK 第一主线的对应

- **短/中/长**：短期可拿部分或查明障碍；中期为特定方法准备工具/学技/制作；长期自选保全知识路线或材料路线，没有强制终局。本轮不自创高阶主线。
- **行动相互支持**：劳作赚钱买绳、炼符用于探索、学抢修减少局部风险、探索材料回制作、训练/休整推进回访时机；不是每轮同一危机。
- **延迟后果与回访**：选择改变实例与通路；时间条件从正式时钟读取。不是只给“好感+1”。
- **失败仍继续**：损失是现场机会/投入，部分所得与世界活动保留；残余入口是真消费者。
- **人物动机/记忆**：复用现有知情来源与记忆，不自动把局部发现广播给全世界、不替 NPC 表态。新同行系统本轮不做，原因是避免只有标签没有消费者。
- **能力/装备/资源**：使用确有来源的符、绳、舟楫、抢修及材料；成本前置可见，奖励有限，六色与段位独立。没有免费私人频道、战舰、组织资格。

## 11. 实施中的独立设计复核与交付边界

2026-11-03 只读检查规则、Story、UI 源码后，已确认设计被接到以下真实消费者，而非仅写世界书：

- `explore_herb_cave.go`、`explore_tide_boat.go`、`explore_service_bay.go` 各有独立定义；特殊方法分别使用符、持有绳/舟楫技能、抢修技能与合金丝，普通慢行仍可完成。
- `story_realm_explore.go` 将实际库存、冻结技能成本、所得与正式时间放入同一提案；重入需回到真实入口，探索不能绕过正在进行的战斗。
- `realm_shortcuts.go` 提供六条新的有名双向路线。只完成回访开门不算到过侧区，须真实移动后才取得该分支的地理知识；不要求把缓存奖励取尽。
- `core_taken` 由成功拆取或侧区取料共同记录，残余回收排除该事实，避免“完整材料到手后故意受挫又多拿一份”。受挫仍有退路，压力与处置不因退出刷新。
- `RealmExploreBlock.tsx` 展示确定的风险变化、耗时、真实成本、条件不足、触线警告及已打开的回访状态；按钮仅放入行动草稿，不结算、不强制领奖。

独立复核者在 2026-11-03 实际执行 `GOMAXPROCS=2 GOCACHE=/tmp/ta-designer-go-cache GOMODCACHE=/tmp/ta-designer-go-mod /workspace/scratch/eb59d401477e/ta_next_20261103/tools/go/bin/go test ./internal/exploration`，结果 `ok ta/internal/exploration 0.032s`。这只证明纯规则包当次通过，不等于正式提交通路或真实模型试玩。Story、App、API、制作链及 UI 的实际执行命令和结果以实施者验证报告为准；本设计审阅不以看见测试文件代替它们的通过证据。最终仍须确认正式提交通路、三世界行路到入口、冷重开/分支、代表制作消费者和小屏界面的实际验证结果。未经模型 API 授权，**自然输入到动作映射、长篇 AI 叙事一致性及长期真人耐玩感仍未验证**。
