# 启动说明

本包是 DENOVA 底座上的**游戏专用自制版**。双击根目录的 `启动.bat` 即可进入已经集成并验收过的版本。

---

## 一、最短路径

```
双击  E:\游戏\游戏开发\DENOVA自制版\启动.bat
```

脚本会：

1. 使用本包**自己的数据根** `.ta-game/`（不读、不写原版安装目录，也不碰你真实的数据目录）；已有 `.denova` 或 `.nova` 时沿用旧目录，不会另开一个空目录；
2. 使用**本包自己的端口** 19720（被占用时自动顺延到 19721、19722…）；
3. 设置真实模型网关环境变量；
4. 启动 `TA.exe` 并自动打开浏览器。

首次运行如果根目录还没有 `TA.exe`，脚本会先自动构建一次（见第三节）。之后每次启动都是直接运行，不再重新编译。

---

## 二、启动前需要满足的条件

| 依赖 | 说明 | 缺失时的表现 |
| --- | --- | --- |
| 模型网关 | `http://127.0.0.1:8317/v1`，模型 `deepseek-v4.1-flash`，已写入 `config.toml` | 界面能打开，但生成正文会失败 |
| `TA.exe` | 根目录已随包提供 | 缺失则启动时自动构建 |
| Node.js 20+ | 仅构建前端时需要 | 仅在自动构建时报错 |
| Go 工具链 | 仅编译后端时需要，随包放在 `.ta-toolchain\` | 仅在自动构建时报错 |

**网关不需要 API Key，并且已经预配置好了。** 模型连接写在根目录的 `config.toml` 里（`[[model_endpoints]]` / `[[model_profiles]]` / `[agent_models.*]`），启动后新建故事、主叙事、人物聊天和传音都可以直接使用，**不需要先去设置页填 API 地址、模型和 KEY**。

`启动.bat` 会主动清空 `OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL` 三个环境变量。这样做有两个原因：从别的工具继承来的值优先级高于 `config.toml`，会把请求指向错误的地址；而清空后加载器会跳过环境变量覆盖，正好让 `config.toml` 生效。

`config.toml` 里的 `api_key = "wb-local-placeholder"` 是**固定占位符，不是凭据**。本机网关不做鉴权，但客户端要求 `api_key` 非空——空值会让设置页和首启引导把模型误判为「未配置」。这个值可以安全提交。

想换成别的模型，在设置页改即可：设置页写的是用户层，会覆盖 `config.toml`。

Go 工具链随包放在本目录下：

```
<本包目录>\.ta-toolchain\go
```

`scripts/toolchain.bat` 负责把它接进 PATH 并设置 `GOTOOLCHAIN=local`。这样即使机器上完全没装 Go，`rebuild` 也能跑通；换机器时把整个包目录一起复制即可，不需要额外安装。该目录已被 `.gitignore` 排除，不入版本库。

如果这个目录缺失，`toolchain.bat` 会依次回退到 `%LOCALAPPDATA%\denova-toolchain\go`、PATH 上的 `go`，以及 `%ProgramFiles%\Go`、`%LOCALAPPDATA%\Programs\Go`、`C:\Go` 这几个常规安装位置；全都找不到时打印明确的修复步骤（把 Go 1.26.6+ 解压到 `.ta-toolchain\go`），而不是含糊地报错。

## 三、构建与重建

| 命令 | 行为 |
| --- | --- |
| `启动.bat` | 有 `TA.exe` 就直接启动，没有才构建 |
| `启动.bat rebuild` | 强制重建前端与后端后启动 |

`rebuild` 会依次执行：准备 Go 工具链 → `pnpm run build` 构建前端 → 把 `web/dist` 复制到 `internal/webfs/dist` → `go build -tags embedweb` 编译带内嵌前端的 `TA.exe`。

**`-tags embedweb` 不能省略。** 没有这个构建标签，`internal/webfs` 会编译成空实现，`TA.exe` 启动后页面打不开。

## 四、数据和端口

```
数据根    <本包目录>\.ta-game\（已有 .denova / .nova 时沿用旧目录）
端口      19720（HTTP），占用时自动顺延
日志      <本包目录>\log\
```

数据根里会有 `projects/`（工作区）、`presets/`、`agents/`、`projects.json` 等。**这些都是运行数据，不入 git。**

想换数据根或端口，改 `启动.bat` 顶部的 `GAME_PORT` / `GAME_DATA` 两个变量即可。

想彻底重置：关掉服务，删掉 `.ta-game/`，重新启动。剧本包会重新写入世界书，故事线全部重新开始。

> 交付时 `.ta-game/` 是**空的**（首次启动会自动重建），你进去就是干净的第一屏。

## 五、首次进入后的操作路径

1. 浏览器打开后，如出现首启引导遮罩，点「跳过引导」。
2. 侧边栏默认落在**游戏**入口（本包已把默认入口从写作改为游戏）。
3. 进入后新建工作区（一本书 = 一个工作区，可以同时容纳多条故事线）。
4. 在「新建故事线」面板里，**最上方是剧本包选择器**，选一个包点「载入剧本包」。
5. 剧本包会把开局、主角、叙事风格、判定规则和世界书填进下面的表单；这些字段**都还可以改**。
6. 点「开始」，故事按剧本包的世界观开局。
7. 之后在主舞台输入框自由输入推进，或点选项把它填进输入框再发送。

## 六、常见问题

**页面打开是空白 / 报错找不到资源**
`TA.exe` 编译时漏了 `-tags embedweb`。执行 `启动.bat rebuild` 重新构建。

**点「开始」后一直转圈或报模型错误**
网关没起。确认 `http://127.0.0.1:8317/v1` 可达：

```bash
curl -s -o nul -w "%{http_code}" http://127.0.0.1:8317/v1/models
```

返回 `200` 表示正常。

**端口 19720 被占用**
不用处理，会自动顺延。实际端口以启动窗口里打印的 `Backend: http://localhost:xxxxx` 为准。

**启动窗口一闪而过**
从命令行运行 `启动.bat` 看完整报错，或在资源管理器里右键 → 编辑，确认文件没有被改成 UTF-8 编码。**`启动.bat` 必须保存为系统 ANSI 编码（简体中文 Windows 上是 GBK/936）并使用 CRLF 换行**，否则 cmd 会在读取中文时截断命令。仓库里的 `.gitattributes` 已经为 `*.bat` 固定了 CRLF。

**能不能和原版 DENOVA 同时开**
可以。数据根和端口都独立，互不影响。
