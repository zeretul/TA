# 开发版试玩反馈

## 2026-11-09

本轮先验收开发版。每项以实际界面、数据或存档检查为准。正式版由用户继续试玩。

### 世界包与创作

- [ ] 冒险目录移除三国入口，新开局不能再走三国冒险路径。
- [ ] 紫川冒险资料清掉会诱导攻城、接管城池的措辞。
- [ ] 哈利与其他新增世界撤下测试、候选和裁判资料等对玩家无用的字样。
- [ ] 所有世界按公开资料统计，保留幕后条目供主持读取。
- [ ] 所有世界用自己的简介，去掉共用的「行走其间」和玩法宣传句。项目文档保留玩家文案口径。
- [ ] 九套冒险配置的总览和建角统一为三种普通、两种爽文、一种自定义。保留旧模板供旧存档。
- [ ] 创作页分公共区与剧本包区，两处都可保存，共同影响后续回合。
- [ ] 新建角色去掉只供演绎的「悟性」选项与默认标签，保留资质和兵器偏好。
- [ ] 世界局势记录当前世界概况和主要事件，礼数、消息渠道和规则另归资料。
- [ ] 世界局势与旧概况合为一张卡，旧存档可读。

### 主角、行囊与战斗

- [ ] 功法、技能和物品详情只在主角标签下展示，世界与其他人物页各显示自己的内容。
- [ ] 清除插画来源标签和光效免责声明，在项目文档维护玩家文案口径。
- [ ] 技能介绍只写招式的简介与背景故事，去掉掌握记录、条件和公式表，文案遵循公共创作红线。
- [ ] 凡人轻招正常施展不积经脉负担，重招和带伤勉强施展仍受约束，验证实际结算及旧局读取。
- [ ] 建角的基本身份取已选出身，外貌与经历等手填文字先润色，经预览确认后落档。
- [ ] 行囊与背包合用一份物品清单，物品可点开，隐藏属性预算，缺图留空。
- [ ] 增加武器、丹药、任务物品、功法书等分类标签，列表只显示名称与品级徽标。修仙世家的功法补名为「叠锋诀」，「良好」用徽标展示。
- [ ] 技能和技能与研习合为一份清单，家传剑气、引气拳各显示一次，点名字看技能介绍。

### 人物档案与游玩界面

- [ ] NPC 身份、外貌、性格、位置和当前目标合到一张概况卡。
- [ ] NPC 好感度和与主角关系合到一张关系卡，省去重复的「未知」。
- [ ] 聊天等浮窗的缩放拖柄移到右下角，鼠标与键盘可按正确方向缩放。
- [ ] 故事手记与状态页的「本回合变化」显示完整文本，长地点在窄栏内换行。
- [ ] 开局后仍可打开游戏设置，目录旁正常显示世界默认、本局设置与创作红线。
- [ ] 秘境、见闻与事务、资料总览统一弹窗打开，可关闭返回故事。
- [ ] 故事助手从灵感切到分析时，无建议也能显示分析正文，页面不崩溃。
- [ ] 等待短句持续轮播，模型只发出思考或内部工具过程时继续显示，正文出现后自然退场。
