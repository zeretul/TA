## 图册补齐

内置 ImageGen 生成 17 张专属原图，并逐项对照世界、稳定 ID 与设定进行视觉检查。对于部分原提示触发审核的图稿，采用工坊静物、闭合工具卷、带主题徽记的配方册和非功能性工件构图。没有复用其他世界的图。保留高分原图和输入描述于 `.ta-dev/art-completion-0618/originals`、`new-art.json`，预览为同目录 `review-sheet.png`。

17 个条目写入 18 个无损 WebP 变体，仪琳有头像及大图，其余各一个。严格覆盖审计剩余 0，1,123 个当前作者条目均可取图（含 101 个原有嵌入头像）。前代 1,190 个变体和历史 URL 元数据保持原字节/条目；抽查一个旧 PNG 地址重定向通过。Windows 实际服务返回的 18 个新资源逐个校验 MIME 与 SHA-256，Chromium 逐个解码并核对尺寸。

图库底层测试可执行文件两次被 Windows 拒绝启动，未计为通过；审计包测试、严格审计及实际 Windows/Chromium 验证通过。审计测试改用空图册验证缺图统计，不再把某个真实人物或配方绑定为永久缺图。开发源码及两套运行版同步同一个 0.6.18 主程序。替换前备份和回滚清单位于 `备份/历史版本/0.6.18补图前`。
