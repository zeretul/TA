# TA 0.7.0 开发基线

当前有效开发基线为baseline/0.7.0，包含世界适配修复；现用源码、开发、正式及分享均为0.7.0。2026-11-06经用户批准精简Git历史并对齐当前开发分支，工作文件和私人配置没有覆盖。

三个保留的源码阶段为：修复前0.7.0、适配修复、当前文档与工程基线。早期源码来自已核验的0.7.0归档；旧提交编号已转换，新旧映射和原始来源证据保留在资料归档/Git精简记录_20261106。原程序清单中的旧source_revision可用该映射追溯，程序内容并未因Git整理改变。

完整恢复点见[版本保留与恢复](版本保留与恢复.md)和[恢复套件](../备份/恢复点/README.md)。原分散0.7.0源码和程序ZIP已整合到套件，不再维护多个重复备份入口。

新工作树明确从baseline/0.7.0创建。历史推演是TA项目内第二款独立经营游戏，大臣召见、廷议、记忆和当前局势属于核心流程，方案见[历史推演](历史推演_独立模块与大臣记忆方案.md)。

Git与恢复包不包含现用密钥和存档。root config.toml在本机保留并排除提交，config.example.toml为无密钥模板。开发/正式保持本地定制，分享继续使用标准源码覆盖；没有远程发布。
