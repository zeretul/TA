# 0.6.18 研习回执修复

题材研习原来先由规则计算技能与时间，但成功的预结算没有返回给正文。模型可能写出仍须考核才算学会，正式技能却已经入账。

首次接受研习行动时，使用原有规则预结算向模型返回实耗时间与掌握程度，要求按回执重写旧正文。完整研习明确已学会，部分研习只承认进度。已接受的同一行动在补交其它模块时不会重复丢弃正文。结算与正式存档仍使用原有提交路径。

定向回归覆盖完整、部分和重复提交，以及已有世界行动拒绝后的改写路径。Windows 构建通过。用上一轮碎冠诸境隔离档在购买习本后分支，同一研习经本机 DeepSeek 真实复验，正式时间推进 10,800 秒，旧票核账由未学升至 1 级；最终正文把凯尔的核账考核写为实际使用，主角当场找到对票差额。没有追加通过考核才算学会的规则条件。复验记录在 .ta-dev/study-fix-0618。

修复已更新开发版 0.6.18，从新提交的研习回合起生效。正式版随后同步同一研习构建，主程序和两处 SHA-256 清单均已校验，Windows 隔离启动、首页和世界包目录已实测。开发版替换前备份位于备份/历史版本/0.6.18研习回执修复前。
