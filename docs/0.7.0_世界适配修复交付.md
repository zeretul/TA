# 0.7.0 世界适配修复交付

日期：2026-11-06。当前：开发、正式本地、分享三套已同步；应用版本仍为0.7.0。

## 已完成

- 西幻主界面使用正确的冒险战斗面板；未知或声明与实际规则不一致的世界不再默认进入修仙战斗。
- 前后端统一核对实际规则与本局冻结能力，跨题材战斗请求被拒绝，合法旧档保留兼容。
- 世界包可按中英文定义战斗、探索、能力、伴侣、能量名称；工具栏、手机弹窗、错误/空态、资料详情、状态展开页、能量消耗与恢复共同读取本局配置。
- 武侠、星海、西幻使用各自默认词汇；自定义名称可以覆盖。缺少某种语言时回退该语言的默认词汇，不借用另一种语言。
- 无线电群聊区分接通/失联与现场在场，不再把远端接通人数写成在场人数。
- 自定义修仙模块按实际能力保留相关入口及设置，修复固定模块ID误判。用户定制的亲密提示词、演绎与资格源码未变。
- 世界重写时旧客户端遗漏presentation会保留配置，明确空对象可清除；配置在本局冻结，不随作者后来改包漂移。

这些名称只是显示与表达约定，不会凭空授予斗气、魔法、序列或其他尚未实现的机制。冒险方向为斗破、哈利波特、诡秘之主、紫川；紫川按用户设定低武处理。经营方向为三国、崇祯，另走独立历史推演方案。
