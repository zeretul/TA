## 已修复

### A06：见闻录读取同一个提交

新增一次聚合读取，在同一 Store 互斥锁及跨 Store/进程 Story 租约内投影人物、行路、任务、事件及玩家快照。前端改为只消费同一响应，不再将多个接口或父页面旧快照拼在一起。继续执行玩家知情过滤及附件路径脱敏，不触发世界时间、回合或模型调用。原独立接口仍保留，其全部调用场景不属于本次原子聚合改造范围。

回归覆盖同分支另一个 Store 并发行路时的位置/时钟一致性、隐私与 canonical journal 不变、父快照过旧、切换 Story/分支、关闭或卸载后迟到成功/失败。

### A07：敌方决策来源随正式回执保存

在现有唯一 Story journal 的战斗事件与冒险行动回执中保存版本化来源。记录白名单状态及通过规则重验的 AI 参与者 ID，区分 AI、部分降级、不可用/上下文/非法结果降级、规则决策及未知。没有保存候选技能、目标、推理、提示词、原始服务错误或凭据。

重复命令、冷开与历史接口返回原回执；分支不会继承以后才在另一支发生的决策。旧记录缺字段时继续表示未知，不追补虚构 AI 来源。已同步现有 CombatWindow API 和 TypeScript 类型，未新增可视状态面板；这不证明真实远程模型策略质量或自然连续游玩。
