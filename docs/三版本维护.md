# 三版本维护

当前应用版本：0.7.0。版本号不带字母或日期；版别单独记录。

| 用途 | 目录 | 程序 |
|---|---|---|
| 开发 | TA-开发版/game | local |
| 正式本地游玩 | Text Adventure/game | 与开发完全相同的local程序 |
| 分享 | TA-github/game | share；原版标准亲密表达 |

## 共同基线与允许差异

分享从未修改亲密模块的最后0.6.18源码基线维护，合入通用修复、明确拒绝/JSON兼容及本轮人物规则。不是直接将私有程序换名分发。最后由本会话交付的0.6.18原程序SHA-256为67e94c24ffee2a939fcdb9bb48d326c8f0aea430ae6229e0b445456bba1ca41c，保留在用户指定备份目录中。

通用源码、前端、世界包和媒体共用。仅亲密提示词、相应生成调用及本地专用辅助文件存在版别差异；本机配置与私人数据不属于共同发布内容。用户给出的另一个819,780,096字节0.6.18程序也原样保留，但不是本会话上次交付的同一哈希。“0.6.18_双修成人向提示词修改前”目录实际只有原程序，不能称为完整源码备份。

## 构建与同步

使用[scripts/build-editions.ps1](../scripts/build-editions.ps1)的local/share选项。前端改动后先按项目构建要求更新web/dist和internal/webfs/dist。该脚本读取web/package.json的数字版本，输出程序，不自动安装或发布。

[分享基线](../tools/release/share-baseline/README.md)保留干净实现及哈希检查。差异文件若被其他Agent修改，share构建会停止，必须核对并将公共修复同步到干净基线，避免丢改动。不要直接覆盖本地专用提示词，也不要复制整个开发目录进分享。

同步前记录受保护数据和回滚来源；同步后核对game/edition.json、SHA256SUMS和实际启动版本。分享使用独立的.ta-game与19724端口；正式为19720，开发为19921，避免串目录或占同一端口。

## 本机与公开发布

三处均是本地目录。日常共同程序更新按用户约定维护三套；发布到GitHub远程或其他公开服务仍需明确发布指令。本机密钥、存档、日志、旧备份和开发源码不进入分享运行包。

备份中的独有历史资料保留；展开安装副本经压缩与逐哈希核验后才删除。整理清单与交付结果见[本轮记录](0.7.0_人物关系与三版本交付.md)。

本机有效Git基线为baseline/0.7.0，包含已核验0.7.0源码与后续适配修复，详见[开发基线](0.7.0_开发基线.md)。当前工作目录的旧HEAD不作为新工作树起点。每次有前端更新时，除web/dist和internal/webfs/dist，还必须将同一构建同步至三套运行目录的game/web。运行程序优先读取旁边的web目录；仅更新TA.exe不能证明玩家得到新前端。安装后读取实际HTTP静态文件并比对构建哈希，同时更新game和安装根目录SHA256SUMS。

2026-11-09 分享版按冒险范围单独构建。历史推演及三国随开发返工，当前分享的前端、主程序与媒体均独立验收。开发和正式的 0.7.0 继续使用同批 local 构建，分享包的准确范围见[分享基线](../tools/release/share-baseline/README.md)。
