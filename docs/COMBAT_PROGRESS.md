# 0.6.17 战斗与成长增量

## 实现范围

以已全量校验的 0.6.17 移交源码为基线；没有覆盖正式版、旧开发包或玩家数据。以下是真实已接入战斗求解与 Story 持久化的切片，不代表整个开放世界和长期成长目标全部完成。

- **修仙战术**：从本人已学且付得起的技能中选择，考虑同场目标数量、准备中的招式、护盾、燃烧和迟滞。可见敌人蓄力时选择自身护盾，不再误把护盾套给对手；群攻明确指定并正式结算多个对手；单敌不为更弱群攻白花灵力。装备实际驱动费计入资格，延续撤退/投降与已付款蓄力规则。
- **武侠/星海战术**：对手按本人伤势、气力、实际来袭和技能用途选招，不再固定轮换。绑定NPC当前已学技能取代旧静态招式列表，正式时间中学会的新技能能在后续战斗实际施展，非战斗技能不阻断玩家回合。
- **真实代价与装备**：治疗、回气、防御不附送普通攻击或耗弹；技能材料与武器弹药整体校验。防守只抵消本回合实际来袭，不抹掉旧伤。NPC已有中毒带入交战，已拥有且装备的舰机计算工具参与技能。武器攻击技能保留激光类型，真实敌方护盾可拦截。
- **已观察招式**：Battle只记录本轮真实施展的技能ID，战斗窗只公开对应名称，不显示未来招式、整套技能或库存；无回应/下一轮未施展时清除。中英文独立标签。
- **持久性**：新增字段可缺省，不要求改写旧存档。沿用既有正式回合提交、命令去重、分支和冷重放；没有增加每日刷、现实等待、额外升级菜单或第二事实源。
