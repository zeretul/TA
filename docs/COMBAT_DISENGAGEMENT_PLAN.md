# 追逃与不分胜负：实现与验收

2026-11-03 15:39 UTC 更新。以下区分实际实现、已验证结果与仍待独立复验。

## 依据与当前缺口

- 用户明确允许双方僵持、不分胜负、一方要走而对方追不上。固定轮数测试未结束不是自动判定哪方获胜的依据。
- 星海原稿中A级旅者的空间遁逃与“追不上我”是具体能力；不存在本地证据支持所有A级对一切舰队必胜。超A级总体对舰描写也不等于免疫资源、环境与舰队规模。
- 冒险旧普通逃跑只计算50+Rank×3，Rank17起必逃，没有对手因素。旧普通攻击等最低1伤害也不允许真正无法破防。两点均不能保留为新规则的真实性依据。
- 凡人既有真实速度逃跑、求饶与接受消费者；冒险AI原来只有普通攻击及真实已学招式；本次已补真实撤离、追击、停战和接受候选。

## 设计边界

- 人舰拆分由单独切片负责：保留敌方Scale并新增玩家参战尺度，旧冻结档缺字段沿用旧行为。追逃统一读取双方实际参战尺度。
- 普通撤离、主动追击、已学付费机动技能与双方停战提议均为真实行动。模型只选系统列出的合法候选，无法填造速度、封锁或资源。
- 已学轻功/实际装备影响机动；仅持秘籍、未装备库存和未来能力不贡献。机动技能必须主动选择并支付原本费用，不把学习当免费常驻高速。
- 对舰能力的Mobility、舰船Interdiction使用明确冻结数据。个人能伤舰、能挡舰炮、能脱离是分别成立的条件。
- 撤离准备进度是0–100的游戏适配量，不伪称物理米数或完整星际几何。主动追击与留守攻击有行动取舍；控制、软筋、封穴、伤势和动力失效仍有实际影响。
- 双方均撤离，或对已公开停战提议达成一致，可结束交锋且不发胜利奖励。保留已有伤势、毒、资源消耗和NPC状态。单方面提议不强制敌人同意。
- 敌人只能看已提交提议与已发生撤离行为，不得看到玩家尚未执行的选择。公开窗口只显示已发生敌行动。
- 无法破防可以造成0伤害；合理僵局不以回合上限强制判胜。资源耗尽造成的实际损失仍照常结算。

## 必须通过的验收

1. 同rank因实际轻功/装备不同而能追上或追不上；高rank无机动不必逃。
2. 低rank付费机动可超过未准备追击的高rank；费用/材料/控制限制不能绕过。
3. 双方主动追逃不额外免费攻击；追不到时可以真实脱离，不刷击杀/经验/钱。
4. 单方面停战仍承受对方合法行动；同意后结束、不回血、不发胜利奖。
5. 先前提议/行动可见，未来选择不泄露；AI非法选择安全降级。
6. 正式Store提交、同command重试、冷重开和分支恢复同一结果与资源。
7. 前端双语行动与状态可操作，双方尺度显示正确；未跑真实浏览器不得声称试玩通过。
8. 老冻结档和现有负担/控制/御使/生成定义/真人在场保护不回退。

## 当前状态

生产实现已合入，关键消费者：

- `adventure_disengagement.go` 负责真实机动、付费技能、撤离准备和对手拦截。普通个人基础为10+rank/2，实配机动物影响基础；主动机动与深空移动取较强者，不把同一速度重复叠加。机动0–100为本游戏适配值。
- 主动追击有+10拦截加成但不攻击，普通留守只用半数拦截；舰船使用实际登记的封锁能力，不以匿名rank1代替。准备量每轮增加3×机动差，追击方更快可消除准备，反复点击不会最终保证抽中逃脱。
- 控制与软筋阻止本轮实际拦截；持续控制减一后不会凭空恢复已失去的行动。已学轻功主动使用时支付能量、材料及反噬，不附送原招式的伤害、治疗或护盾。
- 双方撤离或达成停战结束为standoff；单方提议可以被攻击，模型只看到先前已提交提议。连续三轮无伤害/生命变化的降级策略可提出停战，绝不按固定回合数判胜。
- 敌人成功撤离后状态为enemy_escaped，并从当前在场名单删除其确切人物ID，不能直接按目录ID重开交锋。身份、库存、已付资源与个人状态仍保留；没有假造其新城市或后续行程。失败撤离不移除。
- 前端按玩家实际参战尺度展示技能，显示深空维持费、撤离准备与已公开停战；主动轻功明确只发挥机动，未施展招式不展示为敌人已知行动。
