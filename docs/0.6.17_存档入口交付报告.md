# 0.6.17 存档入口交付报告

开发版与正式版均已同步为纯数字版本 **0.6.17**。本轮只改动存档入口、跨世界存档读取和删除后的选择恢复，没有新增玩法或修改规则。

## 玩家操作

游戏页面顶部常驻三个文字按钮，手机宽度下仍完整展示：

- **新开一局**：在游戏内弹窗选择世界，复用已有世界加载与创建角色流程；仅查看或取消不会建立新局，创建新角色保留原存档。
- **切换存档**：列出所有可用世界的故事，显示世界、角色、回合与更新时间，支持搜索。读取列表不切换当前世界，点击“继续”才切换。
- **删除存档**：先选择目标，再确认世界、角色、故事名称以及全部分支的删除范围；取消不删除。复用原有停止运行、清理绑定与附件的处理。删除其他世界存档后恢复原先世界；删除当前/最后一个存档后清除失效选择。

旧“故事线”菜单仍可用于当前世界内部的故事选择与管理。
