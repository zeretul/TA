# 0.7.0 四世界统一：交付与复核（2026-11-07）

## 结果

已完成串包修复、四包既有作者数据统一、凡人重要中英文世界书补齐，以及自定义世界适配边界收敛。开发、正式本地游玩、本地分享三套均已更新，应用版本仍为 **0.7.0**。没有公开发布。

最新设计原则见[世界包统一与适配边界](0.7.0_世界包统一与适配边界_20261107.md)：先用世界规则和 AI 推理，底座保存和校验已确认结果；特殊或单一机制优先复用现有能力，不为每个机制另造系统。既有精确结算保留并隔离，不把它扩成任意规则脚本引擎。

## 本轮修复与内容

- 三个非修仙世界即使场景文字同为“公共坊市”，也不能列出或直接提交凡人路线；拒绝不改变时间、位置或资源。
- 路线、任务、探索、事件、协作及既有开放条件归各包；物品、技能、功法、配方、天赋与修仙参数按本局快照读取。查询、正式提交、冷重开、分支和撤回使用同一来源。
- 显式空目录不继承默认库；生成技能、NPC 用药、交易货源、战斗普通攻击、地点回执和英文任务展示也已检查本局来源。
- 删除世界版本白名单和地方事务按世界名判断的分支。新包与新版本不需要在代码中登记名字。
- 修复同名自定义包另存时内部归属未同步的问题。创建世界提示词不再禁止世界规则，改为要求自然语言描述触发、代价、限制、可观察结果与延续。
- 凡人新增 19 条中英文资料，总计 142 条。原 107 条人物资料与源码基线逐项比较一致。后期具体资料不再无条件常驻，按实际阶段/地点取用；按名称、ID、索引搜索和常驻上下文均不能绕过过滤，作者编辑器仍可查看原始资料。
- 整理了重复价格、行程、寿元、制作数字以及直接公布后期奖励和解法的正文。未声称做过原著逐章考据。

世界包内容版本：凡人 32、澜川 8、星海 8、碎冠 3。世界书条目分别为 142、274、273、370，条目数不等于玩法规则数，也不是完整性指标。

## 最后复核特别检查

1. 两套不同修仙参数同时建档、修炼、询价并冷重开，属性、增长、价格和商户资金各自保留。
2. 空的目录/生成模板不会被全局默认定义补回；模型上下文使用本局可用模板，完整作者目录不直接注入叙事上下文。
3. 自定义“誓约岛/记忆房间”使用既有 StateUpdates 保存模拟 AI 推演结果，重开与分支隔离通过；没有新增誓约计算器，也未继承无关战斗或修仙模块。
4. 全局目录调用、未知世界/版本、同名另存、应用展示与正式提交逐项复查；此前遗漏的生成、翻译、NPC 用药和货源读取已收口。
5. 变体清单全部核验；本地定制与分享基线仅共同补了两个资料取用调用参数，未重写私有提示词或演绎流程。Windows CRLF 约定下的差异空白检查通过。

## 实测限制

真实外部模型的多规则推理质量尚未验证。本轮探测 `127.0.0.1:8320` 仍不可连接；没有启动、重配或替换共享模型代理。单一机制用例证明现有提交/存储边界可承接结果，不证明任意新机制都已有精确执行器。超出现有能力的精确结算仍需先识别实际缺口。
