# 星海与澜川开场人物数值映射

## 依据与边界

- 依据本包候选世界稿、作者 world 条目的 W01 与 P01–P60，以及当前人物身份，不把小说未来成就或旧十级数值直接换成最高境界。原稿没有逐人精确等级，以下数字是本游戏自制映射，不是原作官方等级。
- 两包内容版更新为 5；旧局的冻结规则与人物状态不做自动迁移。星海已有超 A 人物位于 41–50，开场没有任何人物被预设为超神。韩萧仅为初入星际的 C 级机械师，海拉为 C、卡罗特为 E；珍妮仍是普通人。
- 澜川原先“四层相对火候”继续由技能火候体现。新增人物阶段将成名宗师与初学者分开；令狐冲开场面壁，不预带尚未在本局学到的独孤九剑。
- 角色生命/能量按本次等级差增加 20/10，保留旧作者身体差异与既有伤势；不统一抹成同一生命值。新增或补齐的装备必须真实持有，弹药/工具/使用资格逐一检查。
- 主要人物的会面交战入口没有刷钱/刷历练奖励，且 requires_presence 必须绑定已建立、正式场景在场的真人，不能从目录凭空生成替身。仍无舰队/宇宙尺度战斗模拟。
- 原稿中“黑星军团元老”“圣所复苏归来”等后期措辞与689年并非完全一致。本次没有改写人物履历或自动安排复活、入团；其资料只是尚未发生到场事实的作者定义，不能宣称这些时间线文本已全部校正。

本批再次复核后，将早期草案中的韩萧 B 级下调为 C 级23：世界稿明确是刚离开海蓝星的初创佣兵团时期，不能借用后来稳定 B 阶的成绩。原作阶段参考仅用于避免提前授予成就，压缩数值仍为本游戏自制。

## 新增真实战斗内容

星海新增9项人物尺度技法：定向械力束射、凝域力场崩压、星际沉劲破军、念流断续冲击、折界回光术、高能聚束贯击、并联械力火网、衰竭能量点射、碳晶锋幕；以及折叠械力聚束器、相位编织长袍。既有札记、前置技能、等级与工时仍是学习来源，新增两件装备通过市场购买并需实际使用资格。聚束器每次攻击消费已有武器电池，不是无限免费火力。

武侠另新增“武当连环短打”，由纯阳无极功与后天札记支持，供武当两侠、沈孤鹤和合法学习的玩家使用；修复旧技能组合只有护御/回气、实际求解器永远只守的问题。两世界本次共新增10技法、2装备。

主要人物个人会面入口新增星海15个、澜川8个；原有绑定真人的8个对手同步新等级/身体。会面入口的地点只采用本世界已登记地点或其本人已有出场标签；真正开战必须读取正式场景的在场身份，因此同一人物在别处的已成立会面也可交战，不从作者籍贯推断已经到场。所有真人的技能与装备读取实际快照，不把对手目录里的旧技能列表当作成长后的完整能力。
