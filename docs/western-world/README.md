# 碎冠诸境：隔离候选世界包

**这是独立四世界开发候选。** 原三世界已另行交付，主线未被本包覆盖。本包有完整 Windows 程序和源码、自动化验收与明确待验范围，不能把候选等同于 Windows 原生或自然模型已验。

## 已制作的内容

- 旧帝国解体七十三年后的原创西幻诸境。烬河与渡鸦桥镇、断旗堡、沉钟林、铜脊矿城、镜湖、无名王庭、雾湾与最后古灯塔、灰穗地方生活，共 8 地区、48 地点、140 条定时路线。
- 60 名有具体生活、外貌、声音、目标、背景及人物关系的成年 NPC，12 个组织。人物并非见面就信任玩家；正式与临时加入走现有真实申请、在场联系人接纳及故事记录。
- 7 个可选生活出身；64 个可实际学习的技能、130 个道具、20 个真实耗材配方、10 个有当地货品和工作报酬的市场、54 个明确规则的遭遇，其中 19 个绑定实际实名人物，未在场者不能被战斗菜单召出。没有职业锁定。
- 38 个事务，82 个选择，6 个要求经过时间并实际收到回响的后续事务；其中两条是三阶段调查。它们只约束明确结算的部分，不把全部自由叙事写成任务树。
- 独立古灯塔探索复用既有探索引擎：3 区域、12 动作、有限材料、可离开、可保全/取材、延后返回、互斥记录结果和冷恢复。
- 中文作者源与独立英文显示资源。中文作者事实不会被英文显示反写。

## 三条可玩的准备路径

1. **桥镇生活**：以行路人开局，在桥头工作获得真实银铢，购习本、锻修具和铁木，花时间学习冷锤锻造，制作一把实际入账的剑；再与练习木靶交锋。桥梁事务可选择带料修复或协商时段。回响须等世界时间和与当事人的真实接触。
2. **倒旗墓道**：先读铭文或询问乔文，之后用铁料、辉晶和锻修具修复，或先在正式战斗中击败铁壳誓卫。只有拿到旧闸钥才能归还或保留。两种处理保存不同物件与故事结果。
3. **沉王水宫**：确认潜工走过的路径，牺牲长绳取匣或先击败守库构装。拿到刮改账册后，要真的走到外城或黑蜡下街才能交付或出售。账册不会同时留在背包、交给街坊又卖给商人。

这些路线不是强制主线；可以不参加、改走别处，或让 AI 根据已知事实处理其他合理行动。没有强制王位结局、日常打卡或自动入会。

## 共用底座与适配

现有 Story journal 继续负责命令幂等、分支、旅行、时间、钱物、战斗、组织及探索。没有新建第二份世界状态数据库或第二套战斗引擎。

适配集中在：注册新世界与 `fantasy` 题材；精力名称；规则/资料本地化；新包事务版本准入；探索定义注册；通用 AI 地方事务按冻结实际地点准入、事务可选实际参与人门槛、共用配方的可选 `required_tool`，以及成功选择后交给实际人物的可选 `item_handovers`。工具保留，普通材料消耗；实物交付与玩家扣物处于同一事务，失败保留未交出的原件。空字段保持旧包行为，不根据叙述猜接收人。

`adapter.patch` 只便于人工审查既有文件改动。实际安全导入使用 `import-manifest.json`、`overlay/` 和脚本，不能把候选的整个运行图目录或整个路由文件覆盖到主线。

## 导入操作

在主线稳定且已获合并安排后，从候选目录执行：

```bash
python apply_candidate.py /absolute/path/to/TA-source
```

默认只读预检，不写主线。它会验证每个候选文件的哈希、每个待修改主线文件的精确原版本、路线与图片条目的冲突，也逐字节核对两份合并增量的哈希。主线发生新修改时整次拒绝，不会用旧候选覆盖。

确认候选已经通过需要的验收后，才可执行：

```bash
python apply_candidate.py /absolute/path/to/TA-source --apply
```

脚本先完整预检，再保存备份，只导入本包文件，并按 ID 合并新路由和新图清单。写入出错会逐文件尝试恢复；某个文件无法恢复时仍继续恢复其余文件，明确报告未恢复项与备份位置，不伪报“没有应用”。备份在目标源码 `.ta-dev/before-sui-guan-<时间>/`，附恢复清单。重复导入没有重复奖励或重复条目，也不会复写已相同文件。不要用本操作代替测试、发行构建或正式游玩目录安装许可。
