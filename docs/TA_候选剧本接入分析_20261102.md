## 二、真实可复用边界

当前候选的 `internal/storypack/storypack.go` 定义Pack，`world_draft.go`定义可生成的WorldDraft；`presetlayout.StoryPacks`管理数据根下的 `presets/story-packs`。包是JSON文件，**不是图数据库**。载入、建角、世界书材料化和Story冻结都有现成路径。

当前通用方案 `world-actions-v1` 支持明确确认后的属性字段及绑定，只有 `search`、`evidence_review`、`persuasion`、`chase_or_escape` 四类注册动作。字段数量1—8、字段值范围受校验（当前0—20以内），属性与检定加成并非无限自定义公式。通用方案的成长/独立战斗为 `none`，通信为 `local` 或 `letter`；完整修仙方案单独存在。

所以：武侠书信、交涉、查访、关系与生活可先接；**内力成长、真实武学效果、点穴、毒雾、枪械射击、机械制造、舰船战斗和超能等级，并没有对应的完整题材方案**。电话/无线电也不是目前WorldGameplay的独立通信枚举。不能用“传音改名无线电”或“灵石改名伊纳”宣称完成适配。

## 三、内容到现有结构的映射

| 原稿内容 | 现有承载位置 | 整理要求 |
|---|---|---|
| 世界概况、时代、开局氛围 | `Pack.name/description`、`story.origin`及世界书 | 对玩家写自然简介；世界共同事实与本次开局具体事实分开 |
| 地点/势力 | `world[]`的相应类型条目 | 稳定ID、别名、地域词；地点正文不自动变成已注册路线 |
| 人物 | `characters[]`索引 + 一份`world[]`正文 | `source_key`对应`lore_id`；公开brief与作者秘密分区；性别/年龄有依据；当前位置由Story覆盖 |
| 三种出身 | `creation.origins`、起点/所属选项、`protagonist_templates` | 已确认规则生成正式初始状态；原稿“30文/某剑/两个月债务”要分别映射，不靠简介文字发钱发物 |
| 事务与长期追求 | 世界书可发现线索 + 既有事项/任务提交 | 见闻不等于接取；期限起点必须是正式发生的事件；长期追求拆阶段，不强迫照稿顺序 |
| 武学、能力、装备、材料 | 先作为可查资料；需效果的另绑定已登记定义 | 只介绍不等于已学会/已持有；价格、消耗、持续条件和效果需有真实消费者 |
| 强敌 | 人物/地点/动机资料 + 已支持交战定义 | 世界天花板人物可作远景，不能自动投放到新手场景；不同战斗规模不可混算 |
| 日常场景 | 按需调用的叙事素材 | 不逐段设成固定开场，不替玩家选择行为或预定NPC同意 |
| 头像、场景图、视频 | 既有外置媒体清单及世界绑定 | 素材可后补，缺图用诚实占位；不跨世界误套凡人角色头像 |

命名建议：包ID `lanchuan-qunxia`、`xinghai-689`；具体条目使用包命名空间与类别，如 `lanchuan-char-song-laolu`、`xinghai-char-p028`。这是建议值，尚未创建。人物和事务中引用同一实体用同一个ID；别名只用于检索，不用于身份。

## 四、两包具体接入建议

### 武侠先行

推荐首个切片为“潮信渡—澜口/青盐滩”：保留渡口来客开局，围绕宋老橹、蓝阿鲤、谷怀远等已存在角色组织送信、封滩生计与旧物线索。A01与其他事务按正式线索接续；不在开局同时见到张三丰、张无忌、令狐冲和所有掌门。

若先做通用行动验证版，明确它验证人物、地点、事务和书信，战斗冲突用当前合法检定与既有事实表达，不展示不存在的内力数值成长。正式完整切片则先完成少量武侠规则参数与效果映射，再接一个可交涉、避开或交战的对手。

四个武学火候可先作为世界描述；若要影响胜负，必须决定与正式能力/资格的关系。点穴、毒雾、软筋散不能只写“本轮不能行动”就算引擎支持：必须限定作用对象、持续/解除条件与已有状态消费者。银钱需要确定最小单位与换算；公账私产、独有奖励、读档分支各自沿既有所有权和幂等事实，不新增经济模拟。

### 星海随后

推荐先用“朱伯利清障工—酒吧/船坞”切片：修理谋生、欠费压力、一个合作对象、一次可拒绝的委托。原稿40地点、60人物全部可整理入资料，但只按相关地域召回，远景超A级人物有接触门槛，不能开局扎堆。

最小玩法先做技能资格、工具/耗材、时间和报酬。之后再决定是否增加个人战斗；舰船、机械军团、战略级超能与I58免死等要独立排期，不能与人类单体战斗共用一句“伤害×N”。小说时代与人物履历需另做原著/平行改写核对；本轮只检查本稿内部一致性。

三种开局都使用贫困、债务或追杀，节奏高度相似。建议保留高压选项，同时让一条开局具有稳定工作与主动接受委托的空间。黑星是世界NPC，玩家自己的成长和选择仍应有主导性，不把游戏做成被动旁观原主角。

## 五、接入批次与验收

1. **资料整理**：用户确定武侠版本；修星海引用；全量ID/别名/地域/人物年龄与公开秘密分层；保留原稿及哈希。生成可回溯的候选数据，先不触碰正式目录。
2. **规则映射**：决定通用行动验证版或最小完整武侠方案；列出可表达的具体技能物品、未支持效果、钱物与时间尺度。只补已选流程真正缺少的结算/持久化能力。
3. **隔离导入**：复用Library校验、草稿/预览和Pack加载；核新局初态、两世界隔离、故事冻结、非法组合拒绝。完整中文先保真，英文内容另行制作；当前自定义包的中英内容发布路径需专项确认，不默认旁边放一个英文JSON就会自动挂载。
4. **短链验收**：建角→开场→发现当地人物→交谈/接取→实际获得或付出→暂存行动进入下轮→保存→冷重开→死前/选择前分支。所有数值、物品、任务与结果必须可在正式记录中核对。
5. **内容扩展**：切片成立后逐地域补内容；每批增加真实玩法，不一次重跑所有旧模型链。原稿249条/武侠全册的结构齐全不等于全路径都已实玩。

本轮尚未决定：武侠正本、两包首发规则范围、具体数值和特殊效果、星海原著时点核对及英文内容交付方式。建议先确认武侠总案作为正本与“最小完整切片”的方向，再安排实际制作。
