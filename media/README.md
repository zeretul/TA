# 图片与视频

把素材放在本目录，在 `media.json` 中写清属于哪个人物或地点。添加素材后重新打开游戏，无须重编译程序。也可以在人物窗口点“选择图片”。

默认头像已经内置在程序中；外置图缺失时仍会显示原头像。

本地安装清单有124段视频：17段普通人物视频、107段特定交流用途视频，覆盖17名人物。清单只写相对文件名。视频文件单独维护，不随源码提交；源码检出没有视频时，游戏仍能正常运行。其他世界包可使用相同格式。

常用字段：

| 字段 | 填写内容 |
|---|---|
| `world` | 世界包ID；本包为 `fanren-jie` |
| `subject` | 人物用 `character`，地点用 `place` |
| `source_key` | 世界包中的人物ID |
| `scope`、`actor` | 故事中临时人物的故事ID与人物ID；和 `source_key` 二选一 |
| `place` | 已登记的地点名 |
| `purpose` | `avatar`头像、`portrait`立绘、`scene`地点图、`clip`视频 |
| `scene` | 可选，限定出现地点；留空表示该人物或地点的通用素材 |
| `role` | 普通素材为 `general`，特定交流素材为 `intimate` |
| `reviewed` | 写 `true` 表示作者实际看过这个文件并认可它用在此处 |
| `playback_approval` | 本地用户明确授权时，特定交流视频可使用 `local_owner`，由对应活动的私有入口读取 |
| `file` | 本目录内的文件名，不写盘符、目录或网址 |

普通媒体通过审核后才进入播放列表。特定交流视频另可记录本地用户授权，播放时仍按当前活动、同意和成年资料判断。玩家在人物窗口选择的图片按已审处理。

普通人物视频由此前作者逐帧检查过，故 17 条 `general` 标为已审；特定交流视频此前只抽查过单帧，尚不能视为完整视觉审阅，107 条 `intimate` 保留原未审状态，本地播放授权另行记录。此次移除了5条关联到原设未成年人物的特定交流素材，未查看其画面。文件存在不代表人物已认识玩家，也不代表已经取得活动同意。

播放默认静音、单次；可以暂停、重播或主动打开声音。播放不花游戏时间，不改变人物关系。重新打开窗口或游戏不会强制重播。

素材的创作与公开传播权利须另行确认；源码许可不代表人物、图片、视频也已获授权。
