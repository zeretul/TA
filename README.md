# TA 0.7.0 · 2026-11-09 本机更新

开发版的源码与运行程序已更新到 TA-开发版根目录，正式版已更新到同级 Text Adventure。两套目录均可用根目录的「启动.bat」启动。分享版使用上次标准构建。

本轮合入历史经营 R2、五世界 v34、头像显示和规则校验修复。两个 Windows 安装各通过 203 个 HTTP 网页文件、六套世界配置与历史存档冷启动的验收。现用账号配置和存档随原目录使用。真实模型玩法由用户在 WB 检查，12 项 Windows 目录联接检查仍受本机执行权限限制。

运行图片瘦身已安装到开发与正式目录。每套运行文件少约 420 MiB，旧图鉴地址兼容。用户确认的 21 项旧材料已删除。详见[瘦身与复验](docs/交付资料/云端接续_20261109/运行图片瘦身报告.md)。

正式版隐藏的两份旧程序备份已清理，两套运行文件均应用无损磁盘压缩。正式目录文件合计约 715 MiB，实际占盘约 588 MiB。详见[空间盘点与读档验证](docs/交付资料/云端接续_20261109/正式目录空间盘点与无损压缩.md)。

版本详情及清理边界见 [安装与验收记录](docs/交付资料/云端接续_20261109/交付与验收.md)。
